# 가전 고치기

고장 난 가전을 3D로 열어 보고, 원인을 찾아 납땜하거나 부품을 갈아 고치는 웹 게임입니다.
김 기사님이 한 단계씩 알려 주고, 노랗게 반짝이는 곳만 누르면 됩니다.

## 바로 하기

- **이 컴퓨터에서:** `index.html`을 브라우저로 엽니다.
- **다른 기기에서:** GitHub Pages로 올리면 휴대폰·태블릿에서도 주소만으로 할 수 있습니다.
  1. 이 폴더를 GitHub 저장소에 올립니다.
  2. 저장소의 **Settings → Pages**에서 Source를 `Deploy from a branch`, 브랜치를 `main`, 폴더를 `/ (root)`로 고릅니다.
  3. 잠시 뒤 `https://<사용자이름>.github.io/<저장소이름>/` 주소로 열립니다.

> 인터넷 연결이 필요합니다. 3D 화면은 CDN에서 three.js(r128)를 불러옵니다.
> 진행 상황(번 돈, 깬 단계)은 **각 기기의 브라우저에만** 저장되므로 기기끼리 공유되지 않습니다.
